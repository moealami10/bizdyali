# BizDyali — Darija Glossary (source of truth)

All UI copy uses **Arabic-script Moroccan Darija** (Casa reference; understood
in Laayoune and everywhere in Morocco). French/English loanwords are kept where
Moroccans actually say them — never force an unnatural Arabic word.

**How to use this file:** when localizing any BizDyali string, use the
"Darija" column verbatim for recurring concepts. Do not invent synonyms.
If a concept is missing, add it here first (with a Why note) before using it.

Conventions: `فابور` = free · `دابا` = now · `ديال` = of/belonging to ·
`غـ` prefix = future ("غتسجّل" = will be saved) · `تـ...ـت`/`تسـ` = passive.

## Core product concepts

| Concept | Darija | Why |
|---|---|---|
| business (the company) | المشروع | Neutral + professional; "البيزنس" sounds childish in writing |
| business page (the product) | الصفحة | "الصفحة ديال المشروع ديالك"; spoken alt "لا پاج" — never in UI |
| store / shop (physical place) | المحل | The word every Moroccan uses; "متجر" is textbook MSA |
| owner | مول المحل | Distinctly Moroccan, warm; "صاحب المحل" is stiff |
| customer (sing./pl.) | الزبون / الزبناء | Already in use, fully naturalized; spoken alt "الكليان" — never in UI |
| product (sing./pl.) | البرودوي / البرودويات | What Moroccan merchants actually say; "المنتج" sounds like a textbook |
| service (sing./pl.) | الخدمة / الخدمات | Native word, no change needed |
| category (business type) | النشاط | "شنو هو النشاط ديالك؟" — matches how Moroccans describe a trade |
| menu (restaurant) | المينيو | Universal loanword; "القائمة" reads MSA |
| price | الثمن | Moroccan word; "السعر" is MSA |
| prices (section, e.g. Pricing) | الأثمنة | Natural Darija plural |
| offer | العرض | Understood everywhere |
| promotion / promo | البرومو | The word on every Moroccan storefront; "ترويج" is MSA |
| order (noun, generic) | الطلب | Neutral |
| order (restaurant/café) | الكوموند | Borrowed "commande" — what staff and customers say |
| description | الوصف | Neutral label; spoken alt "الديسكريپسيون" — never in UI |

## System messages

| Concept | Darija pattern | Why |
|---|---|---|
| success | past-tense verb + ✓ ("تسجّل ✓"، "تنشرات ✓") | Verbs, not nouns — feels alive |
| error | "كاين شي مشكل: …" | Soft opener; "خطأ" alone sounds harsh |
| confirmation ("are you sure?") | "متأكد؟" | One word, natural |
| empty catalog | "ما زال ما زدتي لا برودوي لا سيرڤيس" | Warm nudge naming both kinds |
| empty list (generic) | "ما زال ما كاين والو هنا" | Plain spoken |
| validation ("please enter X") | "دخل …" / "كتب …" (no "please") | Darija requests use the verb directly; "من فضلك" in every error is MSA stiffness |
| draft autosaved | "خدمتك كتحفظ بوحدها" / "تحفظات ✓" | Reassuring, no "مسودة" |
| welcome/onboarding | "مرحبا!" | Keep it short |

## Marketing (adapt, never word-for-word)

| Concept | Darija direction | Why |
|---|---|---|
| hero "Your business, online" | "المحل ديالك، أونلاين" | Keep "أونلاين" — Moroccans say it |
| "How it works" | "كيفاش خدامة؟" | Idiomatic question |
| "What's inside" | "شنو فيها؟" | Short, curious |
| "No technical skills needed" | "بلا ما تكون معلّم فالتكنولوجيا" | Plainspoken > literal |
| social proof / trust | Use religious-natural touches sparingly ("الله يعاون" tone) only where the general skill allows; never force them | Warmth without piety-signaling |
| brand attribution | "من BizDyali" | Minimal; never translate "BizDyali" |

## Never translate (technical + brand)

`BizDyali` · `WhatsApp` · `Facebook` · `Instagram` · `QR` · `MAD` inside code
(unit tests expect it) · URLs/slugs (`b.html?slug=…`) · emails · `100 MAD/month`
inside `js/store.js` logic — only the displayed copy changes, never identifiers.
